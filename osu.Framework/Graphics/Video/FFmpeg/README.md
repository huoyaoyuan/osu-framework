# Clangsharp Binding Generation Instructions

The sources under this folder is generated by [ClangSharpPInvokeGenerator](https://github.com/dotnet/ClangSharp#generating-bindings).

## Dependencies

```
dotnet tool restore
```
Restore ClangSharpPInvokeGenerator. You can also use `dotnet tool update ClangSharpPInvokeGenerator` to update the tool.

Platforms with corresponding `libclangsharp.runtime.<rid>` nuget package available should be supported.

## ffmpeg source

The tool parses ffmpeg source. You can run the build scripts in NativeLibs to download it, or manually download a copy.

The source need to either have `configure` script runned, or an empty `libavutil/avconfig.h` created. The platform/configuration parameter doesn't matter.

## Generate

Copy the ffmpeg source under this folder.

*Note: currently, the generator leaks original input path on native type info of anonymous types. To avoid leaking the path into the repository, copy the sources under this folder and use relative path.*

For each .rsp file, invoke the command:

```
ClangSharpPInvokeGenerator -F <ffmpeg-source-root> -I <ffmpeg-source-root> "@<filename>.rsp"
```

Or following snippets to generate them all:

#### Powershell

```powershell
$ffmpeg_root = <ffmpeg-source-root>
Get-Item *.rsp |% { ClangSharpPInvokeGenerator -F $ffmpeg_root -I $ffmpeg_root "@$_" }
```

Note: Always quote the @rsp parameter in powershell.

## Review and Versioning

Please refer to https://github.com/dotnet/ClangSharp#generating-bindings for the parameters of the generator. Just exclude things that won't compile.
